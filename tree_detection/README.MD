# Tree Detection

The `tree_detection` module contains YOLOv5 configuration and training artifacts for detecting trees in Google Street View imagery.

## Files

- `Tree_Detection_Model_YOLOv5x/`: model outputs and supporting files from YOLOv5x training.
- `autoarborist_architecture_yolov5x.yml`: model architecture configuration.
- `autoarborist_file_paths_classes_yolov5x.yml`: dataset paths and class configuration.
- `hyp-scratch-custom.yaml`: custom YOLOv5 training hyperparameters and augmentations.
- `training_arguments_command_line.txt`: example command-line training arguments.
- `jupyter_notebooks/`: notebooks for tree detection experimentation and analysis.

## Notes

- Trained YOLOv5x weights are not stored in this repository. Contact the authors for model weights when needed.
